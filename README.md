## Publish with GitHub Pages

1. Create a public repository under Mah Noor's own GitHub account. Name the repository `USERNAME.github.io` for a root website, or any repository name for a project site.
2. Upload **the files inside this folder** to the repository root. `index.html` must be at the top level, not inside an extra nested folder.
3. Go to **Settings → Pages → Build and deployment**. Set **Deploy from a branch**, select **main**, choose **/(root)**, and Save.
4. Open the site at `https://USERNAME.github.io/` or `https://USERNAME.github.io/REPOSITORY/`.
5. After your live URL is known, update the canonical/profile URL and change the Open Graph image URL to an **absolute HTTPS URL** to improve social preview support.
