# Mah Noor — Academic Portfolio (November 2026 update)

A static GitHub Pages site, no build tools needed. Theme: original forest green and ivory with light/dark modes.

## Publishing
1. Extract the ZIP. Upload the *contents* to the root of your `mah-noor11.github.io` repository, including `assets/`.
2. In GitHub Settings → Pages, select `Deploy from a branch`, `main`, `/(root)`.
3. Confirm `https://mah-noor11.github.io/` works; this URL is the planned GitHub Pages address, not verified live.

## Files
- `index.html`, `styles.css`, `script.js` — site files
